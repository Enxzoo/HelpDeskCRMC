# Theme summary

- Framework: Custom PHP/HTML/CSS; no component framework.
- Font: Inter with system sans-serif fallback.
- Primary text: `--ink: #1c1b18`; secondary text: `--muted: #847c6e`.
- Accent: `--amber: #ecc94b`; darker gold: `--amber-dk: #c98a06`.
- Surfaces: `--cream: #fbf6ee`; `--card: #ffffff`; borders: `--line: #ece3d6`.
- Other accents: `--red: #b8231c`; `--teal: #1e7a8c`.
- Common radii: 8px, 12px, 14px, 16px, and pill-shaped controls.
- Breakpoints: 960px dashboard shell collapse; 600px thread/mobile refinements.
- Source tokens and student UI: `public/assets/css/dashboard_student.css`.
- Related concern-card reference (not loaded by the current student dashboard): `concerns-styles.css`.
